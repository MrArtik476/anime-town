## Decided
- Строка /notifications — настоящий <Link href>; markRead(id) вызывается в onClick без await и без preventDefault. Next 16 при навигации помечает висящий Server Action как discarded, но запрос на сервер уже ушёл; так как markRead вызывает refresh() (pathWasRevalidated), роутер после навигации сам делает refresh — шапка получает новый initialCount, и колокольчик на целевой странице показывает 0 без ожидания опроса. E2E это и проверяет (bell → «0 непрочитанных» на странице комментария).
- BellPoller подхватывает новый initialCount шаблоном «предыдущие props в state» (не key): иначе после «Прочитать все» (refresh()) остался бы опрошенный счётчик.
- Первый показ BellPoller — без запроса (счётчик пришёл с сервера); запрос — при смене pathname и при повторном показе из <Activity> (ref пути не null), только на видимой вкладке.

## Watch out
- POST /__test/episode-released уведомляет всех, у кого тайтл в «Смотрю»/«Хочу посмотреть» — на общем моке параллельные прогоны (--repeat-each) склеивали бы чужие серии в твоё непрочитанное. Передавай emails: [свой пользователь]; reply-тесты держи на своих тайтлах (/anime/7, 8, 9), а не на /anime/1, где первая страница обсуждения забита чужими корнями.
- В mock-supabase head:true + count:"exact" — это HEAD-запрос, число берётся из Content-Range; без него getUnreadCount вернул бы 0/ null.
