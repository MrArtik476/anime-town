# Шаг 6c «Тайтлы» — план реализации

> **Для исполнителя:** выполнять по задачам, логика — через `superpowers:test-driven-development`.

**Цель:** администратор правит русское название и описание тайтла и скрывает тайтл с сайта (с возможностью вернуть).

**Подход (вариант А, согласован 2026-11-12; детали — на усмотрение исполнителя):**
- Ручной текст хранится **рядом** с автоматическим: колонки `manual_title_ru`, `manual_description_ru` в `anime_localizations`. Сайт показывает ручное, если оно есть. Импорт Shikimori и машинный перевод эти колонки не пишут вообще — затереть их нечем. «Вернуть автоматический» = очистить колонку.
- Скрытие — таблица `anime_hidden` (один id на строку), читается всеми: её использует кэшируемый код каталога.
- Все изменения — вставкой в журнал `title_actions` (`set_text`, `hide`, `show`); эффект применяет триггер `private.title_apply`, как `admin_actions` (ADR-027). Отдельная таблица, а не новые действия в `admin_actions`: расширить её check-ограничение можно только через `DROP`, который инструмент применения миграций отклоняет.
- Права в базе: серии скрытого тайтла читает только администратор (политики `episodes` дополняются), уведомление «Вышла серия» по скрытому тайтлу не создаётся.

## Решения по поведению

- Правятся русское название и описание; синонимы не трогаем.
- Ручное описание показывается без подписи источника.
- Скрытый тайтл: нет на главной, в каталоге, поиске и в «связанных»; страница тайтла и страницы серий — «не найдено» всем, кроме администратора (ему — с плашкой «Тайтл скрыт»).
- В «Моём списке» скрытый тайтл остаётся строкой с пометкой «Недоступен», без ссылки; из «Продолжить просмотр» убирается.
- Причина скрытия — по желанию, хранится только в журнале.
- Администратор находит тайтл по id AniList; на `/admin/titles` — списки скрытых и изменённых тайтлов и журнал.

## Что проверить особо

1. Сверка с Shikimori и машинный перевод не меняют ручные колонки — unit (в запись не попадают ключи `manual_*`) и на настоящей базе (`rls:check`: upsert служебным ключом после ручной правки).
2. Ручное описание есть → машинный перевод тайтла не заказывается (бюджет DeepL).
3. Пустая строка в форме = «вернуть автоматический», а не пустое название.
4. Повторное скрытие и показ не скрытого — понятная ошибка, строки журнала нет.
5. Кэш: после правки и скрытия страница тайтла, главная и каталог обновляются сразу (`updateTag`).

## Задачи

1. **Миграция** `supabase/migrations/<версия>_admin_titles.sql`: колонки, `anime_hidden`, `title_actions` + триггер + RLS, политики `episodes`, `notify_new_episodes`. Типы в `src/types/database.ts` (до применения — вручную).
2. **Локализация** (`src/lib/localization/`): поля `manualTitleRu`, `manualDescriptionRu` в записи; `resolveTitles`, `resolveDescription`, `needsMachineTranslation`, `mergeShikimori`, `store` (в запись не уходят). Тесты — `tests/unit/localization.test.ts`, `translation-backfill.test.ts`.
3. **Скрытые тайтлы** `src/lib/anime/hidden.ts` (`getHiddenIds`, кэш с тегом) и фильтр в `src/lib/anilist/api.ts`; страницы тайтла и серии; «Мой список», «Продолжить просмотр».
4. **Админка**: `features/admin/title-model.ts` (+ unit), `title-queries.ts`, `title-actions.ts`, `components/title-editor.tsx`; страницы `/admin/titles`, `/admin/titles/[animeId]`; раздел в `AdminShell`, ссылка со страницы серий.
5. **Мок и E2E**: `anime_hidden`, `title_actions`, `anime_localizations` в `tests/mock-supabase/server.mjs`; `tests/e2e/admin-titles.spec.ts`.
6. **`scripts/rls-check.mjs`**: блок «Тайтлы».
7. **Документы и проверки**: ROADMAP (в т. ч. 6b — «слит, PR #35»), ARCHITECTURE (ADR-029), DEVELOPMENT, Obsidian; `npm run verify`; миграция на удалённый Supabase, `rls:check`, типы, советники — после разрешения владельца.
