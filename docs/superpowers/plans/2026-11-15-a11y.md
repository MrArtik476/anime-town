# 7b. Доступность — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** исправить находки A1–A6 аудита и закрепить их проверками axe и клавиатуры в E2E.

**Architecture:** правки только в разметке (шапка, оболочки страниц, страницы «не найдено», сетка каталога, ссылка в админке) плюс один маленький клиентский компонент `SkipLink`. Проверки — новый `tests/e2e/a11y.spec.ts` на `@axe-core/playwright` с общим помощником `expectNoA11yViolations`. Поведение и внешний вид сайта не меняются (кроме ссылки-пропуска, видимой только в фокусе).

**Tech Stack:** Next.js 16.4 (App Router, Cache Components), React 19.3, Tailwind 4, Playwright 1.64, `@axe-core/playwright` 4.14.0.

**Spec:** `docs/superpowers/specs/2026-11-14-quality-design.md` (§4 «7b»), находки — `docs/superpowers/specs/2026-11-14-quality-audit.md` (§3.2).

## Global Constraints

- Ветка `fix/a11y` от актуальной `main`. Коммит, push, PR — только после разрешения владельца; шаги «Commit» ниже выполняются после него.
- Новый пакет — только `@axe-core/playwright@4.14.0` (devDependency), версия — в таблицу DEVELOPMENT.md → «Версии пакетов».
- Теги axe: `wcag2a`, `wcag2aa`, `wcag21a`, `wcag21aa`, `wcag22aa`, `best-practice`. Тест падает на нарушениях с `impact` `serious` или `critical` и на правилах `heading-order`, `region`, `landmark-one-main` любой важности.
- Ширины проверки: 390 × 844 и 1440 × 900.
- Тесты не ослабляются; если мешает фикстура (мок-картинки), чинится фикстура.
- Перед PR: `npm run verify` и `npm run rls:check` — цифры в описании PR.
- Видимый текст и вид страниц не меняются; ссылка-пропуск видна только в фокусе.

## Review Focus

1. **Скрытые прошлые страницы в DOM.** После клиентского перехода `/` → `/catalog` в DOM два `<main id="main-content">` (Next держит прошлую страницу в `<Activity>`). «Перейти к содержимому» должна перевести фокус в **видимый** `<main>` текущей страницы. Тест — Task 2, шаг 1, сценарий «после перехода по сайту».
2. **Две шапки на странице «не найдено».** Страница тайтла/серии рисует `SiteHeader` сама; страница «не найдено» внутри неё тоже получит шапку — на странице должен остаться ровно один `banner` и один `main`. Тест — Task 3.
3. **Имя логотипа на широком экране** не должно задваиваться («Anime Town Anime Town») и должно совпадать с видимым текстом (правило 2.5.3). Тест — Task 1.
4. **Ссылка-пропуск на телефоне 360 px** в фокусе видна целиком и не даёт горизонтальной прокрутки. Тест — Task 2.
5. **Пустой каталог** («Ничего не найдено»): скрытый `h2` над сеткой не должен оставаться над сообщением без результатов как заголовок без содержимого — `h2` только при непустой сетке. Тест — Task 4.
