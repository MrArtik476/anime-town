# Anime Town

Аниме-платформа: каталог тайтлов, просмотр серий, личная библиотека и сообщество.

Стек: Next.js 16 (App Router) · React 19 · TypeScript 6 · Tailwind CSS 4 · shadcn/ui · Motion · Supabase · HLS.js · Playwright.

## Запуск

```bash
npm install
cp .env.example .env.local   # заполнить по мере подключения сервисов
npm run dev                  # http://localhost:3000
```

## Проверки

```bash
npm run lint
npm run typecheck
npm run build
```
